# 피드백 남기는 곳

## 심소은
Titanic

원본 값과 파생 변수가 함께 들어있어서 나중에 어떻게 처리할지 보면 좋을거같아.
그리고 family_size는 잘 나눴는데 age로 cut한거 보면 (0, 12] (12, 18] 이런식으로 되서 12세는 어린이, 18세는 청소년 이런식으로 분류될 수 있을거같아.

Iris

회귀선을 그려줬는데 이거에 대해 어떤 결과를 얻어가면 좋을까?

Wine

df[features].skew().sort_values(key=abs, ascending=False)
이거 하고 로그 변환 후보라고 되있는데 변환하면 얼마나 차이가 있을까?

## 우유정
Titanic

마지막 원-핫 인코딩 히트맵은 변수가 많아 한눈에 들어오지 않으니, 타겟(Survived)과의 상관계수만 따로 막대그래프로 정렬해 시각화하면 가독성이 더 좋을 것 같음.

Iris

하단에 두 개로 나눈 히트맵(일반 상관계수 vs 절댓값)의 비교 의도나 그래프별 핵심 해석을 마크다운 주석으로 짧게 추가해 주시면 분석 흐름을 이해하기 더 쉬울 것 같음.

Wine

변수 스케일이 커서 전체 박스플롯의 다른 변수들이 납작하게 눌려 보이는데, 스케일링 전후 박스플롯을 비교해 주시면 이후 PCA 결과의 설득력이 더 높아질 것 같음.


## 이충희
Titanic
* age 결측치 처리 전에 age_missing 플래그를 남기며 관리하는 점과 결측치 처리 전후 KDE 비교, 로그 변환 전후 왜도 비교처럼 처리 효과를 그래프로 확인하는 점이 되게 좋았음
* model_df에 age와 age_group_*, fare와 fare_log와 같이 중복 정보가 존재하여 상관 히트맵이 복잡해 보일 수 있다고 생각되는데 모델 학습 시에는 중복 정보를 잘 분리해서 학습 진행할 것이라 생각됨

Iris
* 전체 상관과 품종 내부 상관의 방향이 반대라는 것을 직접 발견하고 심슨의 역설로 연결한 부분이 되게 좋았음

Wine
* 구조, 결측/이상치, 분포, 왜도, 클래스 비교, 상관, PCA로 이어지는 흐름이 매우 깔끔하게 정리되었다고 생각됨
* 이상치를 클래스 별로 보는 접근도 추가하면 좋을 것 같음



각 데이터셋별 피드백이 아니라 전체 내용에 대한 피드백이면 지우고 작성해주셔도 됩니다.
