# 주제: 데이터 전처리 및 시각화를 통한 데이터 이해 및 가공 능력 향상

## 목표: Colab 환경에서 다양한 데이터셋을 직접 분석하고, 데이터의 구조와 특성을 파악하며 전처리 및 시각화 기법에 익숙해지는 것을 목표로 한다.

### 1. 스터디 기본 정보

| **항목** | **내용** |
| --- | --- |
| 개발 환경 | Google Colab |
| 데이터셋 | Wine, Iris, Titanic |
| 학습 주제 | 데이터 검색, 전처리, 시각화 |
| 진행 방식 | 개별 실습 → GitHub 공유 → 상호 피드백 → 최종 결과물 공유 |
| GitHub 주소 | https://github.com/A-I-eXplorers |

### 2. 세부 일정

### 1. 개별 실습 및 결과물 업로드 ( ~ 11.22 12:00)

- Google Colab을 활용하여 데이터 전처리 및 시각화 실습 진행
- Wine, Iris, Titanic 데이터셋을 각각 분석
- 데이터의 구조와 특성 파악 및 필요한 전처리 수행
- 분석 결과 및 시각화 결과를 각 GitHub Repo에 Readme.md와 업로드

### 2. 상호 코드 리뷰 및 피드백 ( ~ 11.23 12:00)

- 다른 팀원들의 결과물 확인
- 데이터셋별 피드백 또는 궁금한 점 작성 및 토론
- 각 데이터셋마다 최소 1개씩 의견 제공
- 1인당 총 3개의 피드백 또는 질문 필수

### 3. 최종 결과 및 성과보고서 작성 ( ~ 11.24 12:00)

- 팀원들의 피드백 및 다른 팀원의 결과물 검토
- 자신의 분석 과정과 다른 팀원의 분석 과정 비교
- 피드백을 반영하여 기존 결과물 보완 및 수정
- 최종 결과물과 함께 개인별 성과보고서 작성 및 공유

### 3. 데이터셋별 실습 대상

| **데이터셋** | **주요 실습 방향** |
| --- | --- |
| Wine | 와인 데이터의 변수 특성 및 분포 분석 |
| Iris | 붓꽃 데이터의 변수 간 관계 및 시각화 |
| Titanic | 결측치, 범주형 데이터 등 전처리 및 생존 데이터 분석 |

### 4.  최종 결과물

- **개별 실습 결과물**: 데이터셋 3종 분석 및 전처리 및 시각화 코드
- **상호 피드백**: 데이터셋별 1개 이상, 총 3개 이상
- **최종 결과물**: 피드백을 반영한 수정 및 보완 결과
- **개인 성과보고서**: 학습 내용, 실습 과정, 피드백 반영 사항, 개선점 및 느낀 점

### 이번 주 핵심 진행 방향

단순히 데이터 전처리와 시각화 코드를 작성하는 데 그치지 않고, 다른 팀원의 분석 방식과 비교하고 피드백을 주고받으면서 데이터 분석 과정에 대한 이해도를 높이는 데 중점을 둔다.
